# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The OrganoidEnv team takes security issues seriously. If you discover a security vulnerability in OrganoidEnv, please disclose it responsibly by following these steps:

1. **Do not create a public GitHub issue.**
2. Send an email to `sharmavansh1409@gmail.com` with the subject `[SECURITY] OrganoidEnv Vulnerability Report`.
3. Include:
   - A detailed description of the vulnerability.
   - Steps to reproduce or proof-of-concept code.
   - The potential impact of the vulnerability.
   - Any suggested mitigations.

### Response Timeline
- We will acknowledge receipt within **48 hours**.
- We will investigate and provide an assessment and timeline within **7 business days**.
- Once a fix is released, credit will be given in the release notes (unless you prefer anonymity).
